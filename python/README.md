# Python Programming

A collection of Python programs and laboratory assignments completed during my university studies.

The repository contains solutions covering fundamental Python concepts such as variables, conditional statements, loops, strings, lists, dictionaries, functions, file handling, randomization, basic algorithms, and GUI development with PySimpleGUI.

## Repository Structure

* **Laboratory Work 1** — Basic input, output, conditions, and simple calculations
* **Laboratory Work 2** — Loops, sequences, random numbers, and basic algorithms
* **Laboratory Work 3** — Strings, text processing, validation, and password generation
* **Laboratory Works 4–7** — Not included
* **Laboratory Work 8** — Lists, sequences, validation, and basic algorithms
* **Laboratory Work 9** — Functions, matrices, integration, and data structures
* **Laboratory Work 10** — File handling and text processing
* **Laboratory Work 11** — Dictionaries, encoding, scoring systems, and GUI
* **Laboratory Work 12** — Data processing, random sequences, and binary representations
